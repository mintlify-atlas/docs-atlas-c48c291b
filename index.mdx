## What is Ejercicio Biblioteca?

Ejercicio Biblioteca is a complete library management system for educational institutions. It is built on top of Python using the **CustomTkinter** UI framework and persists all data in a local **SQLite** database.

The system follows a **Model-View-Controller (MVC)** architecture:

- **Modelo** — `Libro`, `Usuario`, `Prestamo` domain objects and `conexion.py` for database bootstrap.
- **Controlador** — `ControladorBiblioteca` provides all business-logic operations as reusable methods.
- **VistaTk** — CustomTkinter views for every module, each consuming the controller directly.

## Design principles

<Info>
  Every write operation in Ejercicio Biblioteca is wrapped in a SQLite transaction. If any step fails, the entire operation is rolled back — guaranteeing data consistency at all times.
</Info>

| Principle | How it is applied |
|---|---|
| **Atomicity** | Loans update book availability in one transaction; donations create both the book and the donation record together |
| **Consistency** | ISBN uniqueness, active-loan checks before deletion, duplicate reservation prevention |
| **Referential integrity** | `PRAGMA foreign_keys = ON` is enforced on every connection |
| **Isolation** | Each operation opens and closes its own connection |
