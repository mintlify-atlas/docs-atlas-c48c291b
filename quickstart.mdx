## Prerequisites

- Python 3.8 or newer
- `pip` package manager
- A terminal with access to the cloned repository

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/stalyn129/EjercicioBiblioteca.git
    cd EjercicioBiblioteca
    ```
  </Step>

  <Step title="Install Python dependencies">
    The application requires three packages: the CustomTkinter UI framework, the `qrcode` library for QR code generation, and `Pillow` as the image backend.

    ```bash
    pip install customtkinter qrcode pillow
    ```
  </Step>

  <Step title="Navigate to the application directory">
    The entry point is nested one level deeper inside the repository:

    ```bash
    cd EjercicioBiblioteca/EjercicioBiblioteca
    ```

    Your working directory should contain `main_tk.py`, the `Modelo/`, `Controlador/`, `VistaTk/`, and `utils/` folders.
  </Step>

  <Step title="Run the application">
    ```bash
    python main_tk.py
    ```

    The application opens a 1200x720 window titled **Sistema de Biblioteca** with a dark sidebar on the left and the Loans view loaded by default.
  </Step>

  <Step title="Database initialisation">
    On first launch, `main_tk.py` calls `crear_conexion()` before starting the UI loop:

    ```python main_tk.py
    if __name__ == "__main__":
        crear_conexion()
        app = App()
        app.mainloop()
    ```

    This creates `biblioteca.db` in the current working directory and bootstraps all six tables:

    | Table | Purpose |
    |---|---|
    | `usuario` | Library members (nombre, carrera) |
    | `libro` | Book catalog (titulo, autor, isbn UNIQUE, genero, disponible) |
    | `prestamo` | Loan records (usuario_id, libro_id, fecha, devuelto) |
    | `multa` | Overdue fines (prestamo_id, dias_retraso, monto) |
    | `reserva` | Book reservations (usuario_id, libro_id, fecha, estado) |
    | `donacion` | Donation records (libro_id, donante, fecha) |

    <Note>
      The `biblioteca.db` file is created in whichever directory you run `python main_tk.py` from. Always run the command from inside `EjercicioBiblioteca/EjercicioBiblioteca/` so relative imports and the database path resolve correctly.
    </Note>
  </Step>
</Steps>

## Troubleshooting

<AccordionGroup>
  <Accordion title="ModuleNotFoundError: No module named 'customtkinter'">
    You need to install CustomTkinter before running the app:

    ```bash
    pip install customtkinter
    ```

    If you are using a virtual environment, make sure it is activated before installing.
  </Accordion>

  <Accordion title="ModuleNotFoundError: No module named 'qrcode'">
    The QR code utility requires the `qrcode` and `Pillow` packages:

    ```bash
    pip install qrcode pillow
    ```
  </Accordion>

  <Accordion title="sqlite3.OperationalError: unable to open database file">
    This usually means you are running `python main_tk.py` from the wrong directory. Make sure your current directory is `EjercicioBiblioteca/EjercicioBiblioteca/` — the folder that contains `main_tk.py` directly.
  </Accordion>

  <Accordion title="ModuleNotFoundError: No module named 'Modelo' or 'Controlador'">
    The application uses relative imports that only work from the correct working directory. Run:

    ```bash
    cd path/to/EjercicioBiblioteca/EjercicioBiblioteca
    python main_tk.py
    ```

    Do not run it as `python EjercicioBiblioteca/EjercicioBiblioteca/main_tk.py` from a parent directory.
  </Accordion>
</AccordionGroup>
